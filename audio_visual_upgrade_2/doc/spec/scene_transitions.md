# 场景转场与 OSD 第六页

用户批准：保留淡入淡出，增加擦除、溶解、百叶窗与四档速度；允许等价优化其他逻辑以满足资源，不降低功能和效果。

- 显示范围沿用背景与封面图像层；歌词、频谱、OSD 保持原有实时叠加。
- effect 0/1/2/3：淡入淡出、从左向右擦除、固定像素阈值溶解、32 像素高横条内从上向下展开（480 行共 15 条）。
- speed 0/1/2/3：16/32/64/128 帧间隔，约 0.2688/0.5376/1.0752/2.1504 秒；默认 effect=0、speed=1。
- 首幅画面直接显示。之后在帧边界接受请求，锁存模式与速度，进度从 0 到 256。进度仅在帧边界改变。中途更改设置仅作用于下次。
- 溶解阈值由坐标组合生成，无跨帧随机状态；每个完整 16×16 块包含 0..255 各一个阈值，像素随进度只从旧变新。端点保证全旧/全新。
- 复用原 scene_blend 的精确舍入和两级流水；掩码 alpha 与 RGB、DE、VS、HS 同拍注册，整条图像链延迟保持。
- 旧画面读取禁用后至少等待一个帧边界，且 old_idle=1 才返回 ACK；期间新旧存储槽持续被保护，保留原串行请求契约。
- 50 MHz 控制值通过扩展的 visual_settings 稳定邮箱传入 25 MHz 域，目的端在帧边界整体提交。OSD 显示已提交的设置，转场引擎使用开始时锁存的设置。
- EXTENDED=1 的 OSD 导航为 0→1→2（5 项）→3（6 项）→4（5 项）→5（2 项）→0。第六页两项为转场效果、转场速度；KEY2/KEY3 双向循环四选项，其他按钮行为保持。
- 新中文填充已有 128 字符像素 ROM 的空闲 95..111 槽；0..94 字符逐字节保持，不增加 BRAM。旧 32 槽扩展行 ROM 不扩容。
- RUNTIME_CONTROLS=0 保持 scene_fade 原 ALPHA_STEP 参数契约，兼容已有工程/测试。

验收：TR-controller-16-combinations（四效果×四速度、帧边界、配置锁存、ACK排空）；TR-mask-endpoints-monotonic（全屏端点/空间遮罩/单调性/溶解密度）；TR-pipeline-raster（逐像素参考与同步延迟）；TR-reset-pending（忙时请求与复位）；VIS-buttons-six-pages；VIS-CDC-colors-effects-transition；TR-OSD-page6-all-choices（独立文字/布局参考逐像素比对）。现有 scene、视觉控制、OSD、split_core 和系统回归继续运行。

资源目标：不增加 BRAM/DSP，不改时钟与约束。综合及布局布线验证是否装入 EG4S20；原移相 SDRAM 路径违例单独报告，不能以仿真通过代替时序或上板结论。
