# TYP2 风险与证据要求

- 旧TYP1已有板上字幕反馈，但setup未收敛。本次须重跑实现，报告实际STA，不以旧报告替代。
- 原Slice仅余103；采用固定大小TYP2头校验，省去动态长度寄存器，并将128bit字形移位寄存器缩为32bit，抵消取行跨块控制开销。综合前不保证净资源结果。
- 取行跨16B块会增加读事务，须测试最大长度文本和图片仲裁争用下的行截止。已用额外83,824字节SDRAM保留固定汉字槽，免去汉字目录访问；真实100MHz厂商模型为截止验收依据。
- 字库范围是GB2312，换歌仍要制作现有LRC1文件；不支持任意Unicode、无限行数或无限字数。
- demo音频仅45秒，LRC表有全歌45行；不擅自替换音频，覆盖报告分别记录。
