# 华文琥珀与紧凑幼圆 OSD

用户已批准 output/typography_preview_20261029/ 的视觉方案并授权实现。画质要求：16级覆盖率，歌词/歌名24px、歌手20px、OSD16px；资源不足只做保持效果的结构优化。

## 接口和存储契约

- 保留旧文字模块供回归；板级 TYPOGRAPHY=1 选择新实现，core 默认0兼容旧fixture。
- 共享取字引擎 `text_row_aa`：clk_sdr、低有效同步复位、start/cancel；输入fc/cnt/grow/small_font/played/bank，输出busy/done/err/width和逐像素写口。所有任务参数在start捕获。字库/字记录均按4word对齐读4word，ack撤req，完整接收并等待done，不提前释放。
- FONT.HZK新格式TYP1，沿用FONT=0xE1000、261696个32bit word容量；全部图像与歌词地址保持。ASC不再装载。新素材生成器扫描卡中所有LRC实际使用字符（含歌名/歌手），按字符去重并加入验证样本字符；不预置完整ASCII。新增或修改歌曲必须重新运行生成器。容量、缺字或笔画边界溢出报错，不截断或换字体。
- 文件头4word：0x31505954、0x00141804、文件word数、字形数量。随后8320word目录；GB2312索引(q-0xA1)*94+(w-0xA1)，ASCII索引8178+(ascii-0x20)。描述符高4bit=A，bit27:23为20px字宽，22:18为24px字宽，17:0为字形相对word偏移。缺字目录为0。
- 每字形24px部分24行、20px部分20行，每行16字节（4word），每字704字节。4bit覆盖率左像素在字节高半，行尾补0。字宽保留真实整数advance，CJK24/20。基线与用户已看预览相同；新增素材字符使用同一字体并检查笔画边界，超出则报错而不剪切。
- 一套8bit×2048双时钟BRAM32K，按1024像素分两bank，bit4为sung、bit3:0为alpha。取字引擎每条扫描行最多640像素；歌词最多19字，标题/歌手最多24字，三个文字区域分时共用。完成后发布{frame,row,width}，像素域同步并在消隐期锁存；一行中不改变可见性，标签不匹配隐藏。无初始化RAM依赖。
- 描述符采用已有帧快照机制；请求参数保持到下一行，toggle经2FF同步。取字在当前扫描行期间准备下一行，bank按目标行奇偶；忙时不覆盖在途参数。复位/取消不发布半行。
- 布局：歌名(32,16)24高、歌手(32,48)20高，框宽160；歌词基线框顶404/436，窗口396..468，行距32；lyric_pick.SC_PX同步改32，保持0.3秒滚行。标题滚动保持40px/s与0.5秒停留。
- `alpha_blend16`精确逐通道四舍五入：(bg*(15-a)+fg*a+7)/15，alpha0/15端点精确。文字在背景颜色处理之后混合；RGB/alpha/de同步。
- OSD三个页面统一(424,16,200,224)，标题y28，正文y66+32*n，文字16px。保留既有按键、自动隐藏、数值范围、攻击历史时间范围。曲线横向320历史点映射至176像素，纵向量程保留56像素。
- OSD字模ROM由旧32px1bit换16px4bit，中文每字仍1024bit，ASCII每字512bit。先绘制真实面板底色/条形/曲线，再混文字，输出仍两拍。
- 取字错误：格式/参数错误0x66，短读/超时0x04，取消0x08；失败width=0，不发布部分文字。已ack事务在取消或超时后进入DRAIN并等待done，防止旧数据污染下一事务；如果底层接受事务后永久不返回done，则保持busy直到系统复位。未ack超时可以直接结束并恢复。
- `gap_cnt`只统计HS时请求mailbox尚未ack的次数，不表示全部缺行；`on_cnt`统计非零覆盖率的显示像素。缺行由行/帧标签判断并整行隐藏。

## 验收

TYP-01：字体缺字/裁切/目录容量/所有卡内LRC覆盖和16级像素一致性。
TYP-02：逐通道全组合混色精确，0/15端点与负差正确。
TYP-03：24/20px中文及比例ASCII、byte/nibble序、逐字高亮、全部字形行、4word事务对齐；缺字/短读/错误头/容量/超时/取消/复位恢复。
TYP-04：双时钟真实BRAM，扫描行交替、居中、标题/歌手滚动与缺行隐藏；不得半行更新或读取正在显示bank的未完成内容。
TYP-05：OSD全三页、边界、数值极值和选中项、16px字模及实际背景混合，延迟对齐；原按键行为回归。
TYP-06：顶层文字与背景颜色、FFT、切歌流水同步，板级展开及原缩小/音视频必要回归。

新bit须另经真实综合/布局布线检查。现有基线已获用户上板正常反馈，但历史STA本身未收敛，不能写成STA通过。
