# 封面抗锯齿、颜色与效果控制（2026-10-31）

用户授权实施、仿真、综合、布局布线和 bit 生成；不下载。资源优化不得删功能或降低显示质量。
2026-10-31 补充：仅支持 S01 标准轮廓，后续素材均采用此标准，不维护 S02 的较小轮廓。

## 显示契约

- HDMI 640×480，布局不变。封面画布 240×240；中心 (160,165)，椭圆半轴 (100,120)。回弹显示边长 240/250/256/260。
- 使用 4 位覆盖率、16×16 子像素采样的轮廓表。边缘与实时底层图像混合，换图渐变期间同样生效。RGB888 SDRAM 布局和完整中文字库保持。
- 素材边缘颜色扩展，不将紫色色键混入部分覆盖像素；单独交付 S01 封面更新包，不能夹带旧 FONT.HZK。
- 频谱沿横向从白色渐变到所选颜色；当前行已唱部分使用歌词高亮色，所有其余歌词使用另一色。歌名、歌手、波纹独立设色。
- 五个独立开关：圆环、封面回弹、柱顶尖峰、频谱柱、色彩联动。默认全开；隐藏柱子不停止音乐分析及其他联动。关闭色彩联动后保留基础饱和度和对比度。

## OSD 和时序

- 面板固定右下角 x440..639/y256..479。保留原三页，新增颜色、效果两页。
- KEY4 长按显隐；短按切项目，末项目进入下一页；隐藏时短按仍换图。KEY2/3 减/加。
- 颜色页六对象共享 10×7 色板；索引 70 为每对象默认颜色；加减在默认及 70 色之间循环。效果页减关闭、加开启。
- 设置切歌保留、复位恢复默认。颜色和效果采用稳定数据 mailbox + request/ack 翻转跨域，像素域帧边界一次提交。
- 颜色 RGB 表使用共享 ROM；保持既有视频与文字管线逐拍对齐，不改变字体、布局、歌词滚动。

## 验收

- AA：四尺寸全像素覆盖率与独立公式一致，边缘混合 0/15 端点及中间级，渐变与层序正确，无色键污染。
- COLOR：全部可选色、64 柱梯度端点和中间值、两色歌词映射；字体覆盖率不变。
- CONTROL：按键切页/对象、默认值、上下界/循环、五开关互不影响、跨域帧提交及忙时更新。
- OSD：原页面内容、右下角边界、颜色矩阵、选择框、五效果项与文字抗锯齿。
- 回归：字体完整加载/五行歌词/缩小写回/场景换图/板顶层展开。
- 综合和物理报告记录真实资源及违例；原有时序未闭合不能写成通过。

## 等价资源优化依据

- BMP_DOWNSCALE=1 时，装载器仅接受不小于目标且匹配宽高比的源图；成功装载后的尺寸恒等于 BG_W/BG_H 或 COVER_W/COVER_H（bmp_load A_HCHK2）。顶层以 BMP_BG_W/H、BMP_COVER_W/H 同时配置装载器与显示几何；默认仍为 640×480/240×240。保留原形状读取握手和帧提交时刻。BMP_DOWNSCALE=0 仍使用原动态尺寸。
- 图层几何使用 10 位接口内部运算，端点加法多保留一位；vln/lcnt 高位仍参加消隐与行启动判定，不会将消隐计数折返到有效画面。
- OSD 像素字库、数字转换和条宽表为原逻辑的精确重排。颜色滤镜采用整数代数合并，保留原 20 位溢出和逐级取整语义。
